# Site de l'AESB
Pour tester : ouvrir le dossier dans VS Code, installer l'extension « Live Server », clic droit sur index.html > Open with Live Server.
(Ouvrir le fichier par double-clic ne charge pas les événements : le navigateur bloque la lecture de events.json.)

Ajouter un événement : ouvrir data/events.json, copier un bloc { ... }, changer les textes, mettre la date au format AAAA-MM-JJ,
déposer la photo dans images/ et écrire son chemin dans "image" (ex : "images/soiree.jpg"). Penser à la virgule entre les blocs.
